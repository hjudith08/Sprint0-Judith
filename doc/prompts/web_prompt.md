# Interfaz web

## Diseño de entrada

Consultar `doc/web_design.md`.

## Prompt de trabajo

> Crea una interfaz web mínima para mostrar la última medición. `app.js` debe utilizar `LogicaFake.obtenerUltimaMedicion()`, mostrar fecha, tipo y valor, gestionar el caso sin mediciones y permitir actualizar mediante un botón. Mantén un diseño simple para la demostración del Sprint 0.

## Criterio de aceptación

La interfaz muestra correctamente los datos devueltos por `LogicaFake` y el botón `Actualizar` vuelve a solicitar la última medición.

## Revisión del resultado

Se comprueba manualmente la representación y se ejecutan las pruebas de `LogicaFake`.
