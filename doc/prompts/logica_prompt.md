# Lógica de negocio

## Diseño de entrada

Consultar el archivo correspondiente de `doc/` antes de generar implementación.

## Prompt de trabajo

> Implementa en PHP la lógica del diseño `business_logic_design.md`. Debe ser independiente de HTTP. Implementa `validarMedicion`, `guardarMedicion` y `obtenerUltimaMedicion`. Usa únicamente tipos de dominio en el diseño y accede a la tabla `Mediciones`. Añade pruebas automáticas para validación, guardado y recuperación.

## Criterio de aceptación

La lógica no contiene rutas ni códigos HTTP y las pruebas cubren las operaciones clave.

## Revisión del resultado

Se compara la implementación con el diseño, se ejecutan las pruebas disponibles y se corrigen diferencias antes de aceptar el cambio.
