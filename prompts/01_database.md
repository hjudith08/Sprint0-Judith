# Base de datos

## Diseño de entrada

Consultar el archivo correspondiente de `doc/` antes de generar implementación.

## Prompt de trabajo

> A partir de `bd_database_design.md`, genera el SQL mínimo para MySQL/MariaDB de la tabla `Mediciones`. Debe tener `id` autoincremental, `fecha` con `CURRENT_TIMESTAMP`, `tipo` y `valor`. No añadas major/minor ni campos que no estén en el diseño. No incluyas credenciales.

## Criterio de aceptación

El SQL crea exactamente la tabla del diseño y puede ser usado por la lógica de negocio.

## Revisión del resultado

Se compara la implementación con el diseño, se ejecutan las pruebas disponibles y se corrigen diferencias antes de aceptar el cambio.
