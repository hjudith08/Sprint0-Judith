# Registro de uso de IA

Esta carpeta documenta versiones consolidadas de los prompts utilizados durante el Sprint 0. Se han redactado para reflejar el trabajo realmente realizado y la implementación actual del repositorio, sin presentar como ejecutadas pruebas que todavía no se hayan validado.

Cada archivo relaciona:

- el diseño usado como entrada;
- el objetivo solicitado a la IA;
- un criterio de aceptación;
- la revisión que debe realizarse antes de aceptar el resultado.

La implementación funcional existente no se modifica únicamente para adaptar nombres o convenciones documentales.
